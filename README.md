# DraftSpin

Translates text files between multiple languages in real time, serving translators, developers, and linguists.

With DraftSpin, you get a lightweight tool that stays out of your way.

**What you get**

- Translates text files between multiple
- languages in real time, serving
- translators, developers, and linguists

- Translates text files between multiple

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftSpin.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

DraftSpin is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
